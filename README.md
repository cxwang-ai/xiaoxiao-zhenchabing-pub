# 小小侦察兵：长征路上的自然天险

赛道与方向：**数智交互 · 历史回望【险阻解码】**。

扮演虚构的普通红军侦察兵，探索激流、雪山和沼泽的自然规律，再动手闯关。v2 三关依次是可选 1–3 趟、每趟 3 人的节奏渡船（默认 1 趟，约 20–30 秒起）、约两分钟的雪山攀登、约一分半至两分钟的沼泽行军。

## 运行方式

1. 在线体验：**【待填写：部署后的公网链接】**。
2. 离线体验：解压 `xiaoxiao-zhenchabing-offline.zip`，双击其中的 `index.html`；保留同目录的 `css/`、`js/`、`assets/`。无需安装软件或启动服务器。

支持 Chrome / Edge / Safari / Firefox 近两年版本，手机与电脑均可操作。手机请在支持 JavaScript 的浏览器中打开解压后的页面，文件管理器的预览可能不支持运行游戏。

首页需输入作者提供的 4 位验证码后，才能开始或继续游戏；刷新页面后需重新验证，已保存的游戏进度保留。此为前端静态入口限制，不提供服务器端身份认证。无需注册账号，不收集个人信息。游戏使用全部本地资源，不联网、不调用在线接口；在线入口首次打开需联网下载页面。进度仅保存在本机浏览器，浏览器存储不可用时仍可游玩，但不能保存；未结算的关卡刷新后从该关出发资源重新开始。改名与规则更新沿用原存档 key 和版本：已完成关卡保留原结果，未结算尝试按当前规则重启。

史实与观测数据仍有占位，请以“待核实 / 简化模型 / 游戏参数 / 已核实”标签区分。角色与插图为艺术演绎；关卡代表点、抵达大渡河月份和夹金山翻越点海拔已按作者资料核实；代表点不表示完整历史行军路线。详见 [科学依据与游戏规则](科学依据与游戏规则.md)。

### 打不开怎么办

如果页面显示加载提示或只有几行无样式文字，说明浏览器没能读取同一文件夹中的样式和程序文件。

1. 确认解压后的整个文件夹完整，保留 `css/`、`js/`、`assets/`；不要只拷贝 `index.html`，不要在压缩包预览中直接打开。
2. macOS 用户：改用 Safari 打开，或把整个文件夹移到“下载/桌面/文稿”以外的位置（例如“共享”文件夹 `/Users/Shared/`），再用 Chrome 打开。
3. 也可使用上方“在线体验”中的在线链接。

## 怎样操作

- 在总图的关卡卡片选择游戏；地图点位和图例只作位置说明。依次完成“看 → 探 → 闯 → 本关字幕 → 史”，再回总图。大渡河、夹金山、草地均可独立进入，自由选择顺序，无需解锁；三关仍共享体力与物资。
- “探”是约 30 秒的侦察简报：选断面看流速与速度合成；拖海拔看气温与相对氧含量；点沼泽剖面看落脚线索和日内气温。来源与核验标签在折叠区，点击底部“开始闯关”进入游戏。
- “闯”中 Esc / P 暂停；各关操作见画布下方提示。触屏设备默认显示虚拟按键；电脑可用“显示按键”切换。
- 三关游戏视窗统一为 4:3，最大 960 × 720 像素；根据屏幕宽度和可用高度同步缩放。页面由用户自行滚动；开始、继续、状态更新与尺寸调整不再强制对齐顶部。准备提示覆盖画布，切换到游戏不改变页面高度。手机画布与虚拟按键的总高度按视口预算。
- 大渡河：“准备出发”页面先选渡口，下一行选择 1 / 2 / 3 趟（默认 1 趟），按钮按趟数显示送达人数（每趟 3 人），再点“开始练习”；选择后画布与下方读数立即刷新；渡口为宽而浅 / 窄而深 / 中等断面；左右转船头，上 / 空格每0.45–0.75秒按一下划桨，下按一下倒划。标准按住不连划；轻松第一下为手动桨，按住后每0.7秒自动划桨，冲量为最佳的80%，不增加疲劳。每桨基础消耗0.035体力，抢桨与碰撞另有消耗；轻松体力耗尽只降低分数与回写资源。送达总人数 = 所选趟数 × 3（虚构队员）；上涨系数按 1 趟 `[0.8]`、2 趟 `[0.8,1.4]`、3 趟 `[0.8,1.1,1.4]` 编排，流速仍为流量 × 上涨系数 ÷ 断面面积；首趟为教学趟，只留一块礁石、无移动漩涡和漂木；多趟时最后一趟障碍最密。选择会保存，重试沿用。船头往左偏，抵消水流；点线显示保持当前船头与最近节奏的预计航线和落点，越界变红，碰撞/漩涡和后续操作会改变实际路线。越界后有1.5秒回划窗口。新游戏默认轻松，第一次玩推荐轻松；耐久低时自动修船，实际使用才扣物资。
- 夹金山：左右移动，空格短按小跳、长按高跳；默认稳步走路并自动恢复氧气，Shift / X 按住才冲刺（手机“冲刺”键）。跳跃与冲刺耗氧，越高消耗越多；氧气不足时提示“喘口气……”，走路、站立或贴着岩块按方向都能恢复，约 5 秒内可再起跳；低氧会降低跳跃高度，宽沟前先喘气再助跑；窄冰台要控制距离，薄冰站上0.8秒裂、1.5秒塌。体温耗尽、跌落深谷或雪崩追上扣一条生命并回检查点。雪崩为游戏设定，史料未记载；减少动态效果时关闭震动。物资决定开局携带的干粮、干辣椒数量，按需自动使用；路边拾取立即生效。
- 草地：地图为9列×20排（原40排减半，南缘10排仍为安全教学段）；领队到达北侧整排出口的任一格即通关，不必收集全部宝箱或全员到齐；界面显示剩余排数与行军进度，抵达后取消未触发的队尾险情。方向键向北走，空格 / 手机“探杆”试探面朝方向的一格；草墩风险低，深草居中，积水反光风险高；白天看周围两格，20时至6时夜雾缩为一格，标准寒冷系数提高到1.5。领队陷入后按住 Shift / X 或手机“救援”自救；队友陷入先沿已确认的脚印走回相邻格，再按住救援。原有连按方向 / 空格 / 救援五次仍可用。头顶倒计时圈：轻松7秒、标准4秒；专用救援键按住持续增加进度，方向 / 空格长按不救援；倒计时归零后队友掉队、剪影留原地变灰并扣1命，领队超时扣1命回上一个安全格。队友陷入时用绿色箭头标出靠近救援的下一格；掉队后明确提示扣命，并标出能通向出口的安全下一格。提示持续到走到目标格，偏离后重新指路；不扣探杆或额外物资，极端围困时补齐最少的安全落脚连接。回救脚步加快；每两次踩陷可能在两步后触发队尾险情，均为游戏设定。目标最多带出3名队友和领队，人数占主要分数，另计用时、探杆确认隐患、生命、失误与剩余体力；确认安全后可快步。雨雹短时减速，低体力时自动使用开局干粮。
- 碰到宝箱会暂停游戏，按 1/2/3 或方向键 + 回车答题。答错不惩罚；夹金山答对恢复体温或体力，累计恢复上限 30；大渡河答对获得修船或短时额外划桨力，累计上限 3 次，携带修船最多 3 次、划桨力持续最多 12 秒；草地答对补 4 次探杆或 1 份干粮，累计最多 3 箱奖励，携带上限为 48 次探杆、2 份干粮。均为游戏参数，整数奖励，关闭答题层继续游戏。
- 每关生命轻松5 / 标准3；雪山、渡河失误或领队超时回安全点，草地队友掉队留在原地；用完则失败。结算显示分数明细、按分数判定的星级、本机最高分及新纪录提示。三关结算分别显示本次分数、最高分、星级与“使用补给”标记；三关总分累加本次成绩，最高分另列合计，重载后仍保留。旧存档无本次分数时明确显示“旧成绩未记录”。
- 通关立即播放本关字幕，可暂停、加速或跳过；减少动态效果模式改为手动滚动阅读。作者短文原文照录。字幕结束后自动进入史料页。完成后可在总图卡片和结算页重看。闯关与史料页右下方统一使用“返回总图”，游戏提示层不再另设退出按钮；已通关的闯关页另有“下一步 · 解锁史料”，可随时继续阅读。
- 每关闯关页均有一个“重新游戏”按钮，准备、倒计时、游戏中、暂停及失败后都能重新开始本关，恢复本关出发资源；已完成关卡也可直接重玩，保留存档中的星级、成绩与资源，重玩成绩可更新本机最高分。连续失败3次后可选“补给后重试”，恢复该关保底入场资源，分数明细标“使用补给”（扣300分）；三关完成后进入结算，“重新挑战”清空进度从头开始，保留所选难度与本机最高分。结算页可“清除最高分”，需再次确认。

跨关资源：每关先计入基础行进补给（轻松8 / 标准12，最多消耗现有物资），余下物资决定道具；保底补足的道具免费。大渡河耐力上限至少40、修船至少1次；雪山耐力至少75、干粮/干辣椒各至少1份；草地耐力至少45、探杆至少8次、干粮至少1份。雪山氧气上限按保底后的耐力计算，最低83.75，仍低于满资源100；低资源最多扣300分。成功结算体力至少10，避免到终点却因继承资源耗尽而无法进入其他关卡。每次失误结算另消耗7体力、2物资；不因回检查点重置账本。生命、保底、资源与时间均为游戏参数。

## 部署到 GitHub Pages（作者自行操作）
